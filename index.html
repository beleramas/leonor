1. Qué es una potencia

Una potencia es una forma abreviada de escribir una multiplicación repetida del mismo número.

an = a · a · a · ... · a (n veces)
a se llama base · n se llama exponente

Ejemplo: 24 = 2 · 2 · 2 · 2 = 16

💡
Cómo leerlo: La base dice qué se multiplica. El exponente dice cuántas veces se multiplica. 24 se lee "dos a la cuarta" y significa multiplicar 2 por sí mismo 4 veces.
Error común: 24 NO es 2 · 4 = 8. Es 2 · 2 · 2 · 2 = 16. El exponente no se multiplica por la base — indica cuántas veces se multiplica la base por sí misma.

2. Exponentes negativos

Cuando el exponente es negativo, la potencia se transforma en una fracción: se "da vuelta" la base.

a−n = 1an
para todo a ≠ 0

Ejemplos clave:

  • 2−3 = 123 = 18
  • 5−2 = 152 = 125
  • 10−1 = 110 = 0,1
Regla con fracciones: Cuando la base es una fracción y el exponente es negativo, se invierte la fracción y el exponente se vuelve positivo:
(ab)−n = (ba)n
Ejemplo: (25)−2 = (52)2 = 254
🔄
Truco visual: Piensa en el signo negativo del exponente como una "señal de vuelta". Si es entero, se convierte en fracción (1 sobre la potencia). Si ya es fracción, se invierte (se pone boca abajo) y el exponente se vuelve positivo.

3. Exponente cero y uno

Exponente cero

a0 = 1

Condición: a ≠ 0

Ejemplos:
50 = 1
(−7)0 = 1
(34)0 = 1

Exponente uno

a1 = a

Siempre válido.

Ejemplos:
51 = 5
(−7)1 = −7
01 = 0

¿Por qué a0 = 1? Observa el patrón: 23 = 8, 22 = 4, 21 = 2, 20 = ? Cada vez que el exponente baja en 1, el resultado se divide entre 2. Así que 20 = 2 ÷ 2 = 1. Esto funciona con cualquier base (excepto 0).

4. Bases negativas (cuidado con el signo)

Este es uno de los puntos donde más se equivocan. Hay que mirar muy bien si el signo negativo está adentro del paréntesis o afuera.

Sin paréntesis: −an

El exponente afecta solo a la base. El signo menos se queda "afuera" multiplicando al final.

−an = −(an)

Ejemplo:
−24 = −(24) = −(2·2·2·2) = −16

Con paréntesis: (−a)n

El paréntesis incluye el signo: el negativo se multiplica n veces.

(−a)n = (−a)·(−a)·...·(−a)

Ejemplo:
(−2)4 = (−2)·(−2)·(−2)·(−2) = +16

Regla de signos para (−a)n:
  • Si n es par → resultado positivo: (−2)2 = 4, (−3)4 = 81
  • Si n es impar → resultado negativo: (−2)3 = −8, (−5)1 = −5

⚠️ Este es el error #1 en la prueba

−24 ≠ (−2)4

El primero da −16, el segundo da 16. Siempre mira si hay paréntesis. La pregunta 1 del control es exactamente esto.

5. Las 5 propiedades clave

Estas cinco reglas son el corazón de la prueba. Si las dominas, resuelves la mayoría de los ejercicios.

1. Multiplicación con igual base

Cuando multiplicas potencias con la misma base, se suman los exponentes.

am · an = am+n

Ejemplo:
23 · 24 = 23+4 = 27 = 128

2. División con igual base

Cuando divides potencias con la misma base, se restan los exponentes.

am : an = am−n

Ejemplo:
25 : 22 = 25−2 = 23 = 8

3. Potencia de potencia

Cuando elevas una potencia a otro exponente, se multiplican los exponentes.

(am)n = am·n

Ejemplo:
(23)4 = 23·4 = 212

4. Multiplicación con igual exponente

Cuando las bases son distintas pero el exponente es igual, se multiplican las bases.

an · bn = (a·b)n

Ejemplo:
24 · 64 = (2·6)4 = 124

5. División con igual exponente

Cuando las bases son distintas pero el exponente es igual, se dividen las bases.

an : bn = (a:b)n

Ejemplo:
63 : 23 = (6:2)3 = 33 = 27

Truco para recordar cuándo aplica cada una:
  • Si las bases son iguales → juegas con los exponentes (suma, resta o multiplicación).
  • Si los exponentes son iguales → juegas con las bases (las multiplicas o divides).
  • Si no se parece a ninguna → desarrolla la potencia como multiplicación repetida.

6. Potencias de fracciones

Cuando la base es una fracción, el exponente afecta al numerador y al denominador:

(ab)n = anbn

Ejemplo: (23)3 = 2333 = 827

Decimales como fracciones

Los decimales también son fracciones, aunque no siempre se vean así:

  • 0,2 = 210 = 15
  • 0,5 = 12
  • 0,25 = 14

Por eso cuando tienes (0,2)−2, conviene primero escribirlo como fracción: (0,2)−2 = (15)−2 = (51)2 = 25

  • A) (12)6
  • B) (12)5
  • C) 25
  • D) 26
Interpretar "la mitad"

"La mitad de algo" significa "dividir entre 2".

Mitad de 26 = 26 : 2
Recordar: 2 = 21
= 26 : 21
Aplicar propiedad: división con igual base → restar exponentes
= 26−1 = 25

  • B) −35
  • C) 53
  • D) (53)6

((35)−2)3 = (35)−2·3 = (35)−6
Paso 2 — Exponente negativo con fracción: se invierte la base
(35)−6 = (53)6

Pregunta 6 Teoría de propiedades

¿Cuál afirmación es verdadera?

  • A) Solo se puede aplicar propiedad a división de potencias cuando los exponentes son iguales.
  • B) Solo se puede aplicar propiedad a multiplicación cuando las bases son iguales.
  • C) Todo número distinto de cero, elevado a cero, es uno.
  • D) Todo número elevado a uno es uno.
Análisis de cada opción

A) Falsa. En la división también se aplica propiedad cuando las BASES son iguales (se restan exponentes). No es solo con exponentes iguales.

B) Falsa. También se aplica propiedad en la multiplicación cuando los EXPONENTES son iguales (se multiplican las bases). No es solo con bases iguales.

C) Verdadera ✓. Esta es la propiedad del exponente cero: a0 = 1, siempre que a ≠ 0.

D) Falsa. Todo número elevado a uno es igual al MISMO NÚMERO, no a uno. (a1 = a)

Respuesta correcta: C)

Pregunta 12 Problema contextualizado

En un videojuego, cada vez que se gana, las monedas se triplican. Si al inicio tenías m monedas y ganaste 3 veces, ¿qué expresión permite calcular las monedas totales?

  • A) m · 34
  • B) m · 33
  • C) m · 32
  • D) m · 3
Analizar qué pasa en cada victoria
Inicio: m monedas
Después de ganar 1 vez: m · 3
Después de ganar 2 veces: (m · 3) · 3 = m · 32
Después de ganar 3 veces: m · 32 · 3 = m · 33
Regla general

Si algo se triplica k veces, se multiplica por 3k.

Respuesta correcta: B) m · 3³
Pregunta 13 Crecimiento exponencial con tiempo

Una colonia de bacterias se triplica cada 20 minutos. Inicialmente hay 5000. ¿Cuántas habrá al cabo de 3 horas?

  • A) 5000 · 33 bacterias
  • B) 5000 · 39 bacterias
  • C) 5000 · 315 bacterias
  • D) 5000 · 360 bacterias
Paso 1 — Convertir 3 horas a minutos
3 horas × 60 min/hora = 180 minutos
Paso 2 — Contar cuántos períodos de 20 minutos caben en 180 minutos
180 : 20 = 9 veces

Entonces las bacterias se triplican 9 veces.

Paso 3 — Aplicar la misma lógica de la pregunta 12
Final = 5000 · 39
Respuesta correcta: B) 5000 · 3⁹
Pregunta 14 Decrecimiento exponencial

Una pelota se deja caer desde 30 m. Cada rebote alcanza 7/10 de la altura anterior. Si n es el número de rebotes, ¿qué expresión representa la altura alcanzada en el rebote n?

  • A) 30 · (710)n
  • B) 30n · (710)
  • C) 30 · (107)n
  • D) 30n
Analizar rebote por rebote
Caída inicial: 30 m
Rebote 1: 30 · (7/10)
Rebote 2: 30 · (7/10) · (7/10) = 30 · (7/10)2
Rebote 3: 30 · (7/10)3
Rebote n: 30 · (7/10)n
¿Por qué 7/10 y no 10/7?

Porque la pelota sube MENOS cada vez (alcanza menos altura). El factor 7/10 = 0,7 es menor que 1, por eso hace decrecer. Si fuera 10/7, la pelota subiría más cada vez (imposible).

Respuesta correcta: A) 30 · (7/10)ⁿ

Pregunta 16 Detectar el error

Marcos calcula el perímetro de un rectángulo de lados 23 y 24, pero comete un error. ¿En qué paso?

  • Paso 1: P = 2 · 23 + 2 · 24
  • Paso 2: P = 24 + 25
  • Paso 3: P = 24+5
  • Paso 4: P = 29
  • A) Paso 1
  • B) Paso 2
  • C) Paso 3
  • D) Paso 4
Revisar cada paso

Paso 1 — Correcto. El perímetro de un rectángulo es 2(largo) + 2(ancho).

Paso 2 — Correcto. 2 · 23 = 21 · 23 = 24, y 2 · 24 = 25. Usó bien la propiedad de multiplicación con igual base.

Paso 3 — ERROR ✗. Aquí está SUMANDO exponentes, pero entre las potencias hay un signo + (suma), no multiplicación. La propiedad am · an = am+n solo aplica cuando se multiplican las potencias. En una suma NO se puede hacer esto.

Paso 4 — Sería correcto si el paso 3 lo fuera, pero como el paso 3 está mal, todo lo posterior también está mal.

Cálculo correcto desde el paso 2
P = 24 + 25 = 16 + 32 = 48
Respuesta correcta: C) Paso 3
Pregunta 17 Pregunta abierta · Justificación (1 pt)

Justifica la propiedad: "todo número racional distinto de 0 elevado a 0 es igual a 1".

Justificación usando la propiedad de la división

Por la propiedad de división de potencias con igual base: am : an = am−n

Si tomamos m = n (mismo exponente arriba y abajo), entonces:

am : am = am−m = a0

Pero sabemos que cualquier número (distinto de 0) dividido por sí mismo es 1:

am : am = 1

Por lo tanto, necesariamente:

a0 = 1 (siempre que a ≠ 0)
Alternativa: con un ejemplo numérico

Tomemos a = 2 y observemos el patrón al bajar el exponente:

  • 23 = 8
  • 22 = 4 (8 ÷ 2)
  • 21 = 2 (4 ÷ 2)
  • 20 = ? (2 ÷ 2 = 1)

Cada vez que el exponente baja en 1, el resultado se divide entre la base. Siguiendo el patrón, 20 = 1.

¿Por qué a ≠ 0?

Porque en la demostración se usó la división am : am, y si a fuera 0, tendríamos 0 : 0, que no está definido.

Cualquiera de estas dos justificaciones es válida. Pueden combinarse también.

🎯 Resumen / Machete final

Todo lo esencial en una sola vista. Si dominas esto, tienes el 90% de la prueba.

Las 5 propiedades

am : an = am−nDividir, igual base → restar exponentes
(am)n = am·nPotencia de potencia → multiplicar exponentes

a1 = acualquier a

(−a)n imparsigno dentro + exp. impar → NEGATIVO

⚠️ Errores que NO puedes cometer

  • Confundir −24 (= −16) con (−2)4 (= 16).
  • Aplicar propiedades cuando hay suma o resta entre potencias (no existe tal propiedad).
  • Decir que a1 = 1 (es a0 = 1, no a1).
  • Olvidar invertir la fracción al cambiar el signo del exponente.
  • Al dividir exponente negativo, olvidar que restar un negativo es sumar.

Estrategia para la prueba

  • ✓ Lee dos veces cada pregunta antes de responder.
  • ✓ Si aparecen números compuestos (como 12, 9, 49, 64), intenta descomponerlos en potencias.
  • ✓ Si la expresión se ve complicada, simplifica primero cada parte por separado.
  • ✓ En los problemas contextualizados, pregúntate: "¿esto crece o decrece?" (crece = factor >1, decrece = factor <1).
  • ✓ Si tienes tiempo, verifica reemplazando con números pequeños.
